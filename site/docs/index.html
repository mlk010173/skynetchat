SKYNET · API e MCP v1.0 Studio de voz Chat

API pública

Fale com o SKYNET por HTTP ou conecte por MCP. Os modelos ficam no servidor: você pede auto e o roteador escolhe o melhor disponível, com failover por latência.

1. Pegar sua chave

Com a sessão da sua conta (o mesmo sky_session do chat):

curl -X POST "https://rkgwhhtenfozdwzpvxjj.supabase.co/functions/v1/auth?action=apikey-new" \
  -H "apikey: <chave pública do projeto>" \
  -H "x-session: <token da sua sessão>" \
  -H "Content-Type: application/json" \
  -d '{"nome":"meu app"}'

A chave sai uma única vez, no formato sk-.... Para listar: ?action=apikey-list (GET). Para revogar: ?action=apikey-revoke com {"id":"..."}.

2. Rotas

RotaO que faz
GET /apiíndice de rotas
GET /api/mesua conta, nível e chamadas registradas
POST /api/chatpergunta e recebe a resposta completa em JSON
GET /api/modelssaúde e latência dos modelos medidos
GET /api/conversationssuas conversas
GET /api/conversations?id=...mensagens de uma conversa
GET /statussaúde geral do backend (público)

Base: https://rkgwhhtenfozdwzpvxjj.supabase.co/functions/v1. Autentique com Authorization: Bearer sk-....

3. Conversar

curl -X POST ".../functions/v1/api/chat" \
  -H "Authorization: Bearer sk-..." \
  -H "Content-Type: application/json" \
  -d '{"message":"Explique o que é MCP em duas linhas"}'
{
  "ok": true,
  "answer": "MCP é um protocolo aberto ...",
  "model": "nvidia/nemotron-3-ultra-550b-a55b",
  "conversationId": "9f2c..."
}

Campos aceitos: message (ou messages no formato OpenAI), model (padrão auto), conversation (ID para manter contexto). Limite de 4000 caracteres por mensagem.

Quem chama com a chave do dono cai na cota do dono; a cota diária segue o nível da conta.

4. MCP (Claude Desktop, Cursor, Cline…)

Servidor em /functions/v1/mcp, JSON-RPC 2.0 sobre HTTP, autenticado com a mesma chave.

{
  "mcpServers": {
    "skynet": {
      "url": "https://rkgwhhtenfozdwzpvxjj.supabase.co/functions/v1/mcp",
      "headers": { "Authorization": "Bearer sk-..." }
    }
  }
}

Ferramentas expostas:

  • skynet_perguntar — manda uma pergunta e recebe a resposta
  • skynet_modelos — lista modelos e saúde
  • skynet_historico — lista suas conversas
curl -X POST ".../functions/v1/mcp" \
  -H "Authorization: Bearer sk-..." -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call",
       "params":{"name":"skynet_perguntar","arguments":{"mensagem":"oi"}}}'

5. Voz

O Studio de Voz transcreve pelo microfone do navegador e fala as respostas com o modelo aberto MMS-TTS rodando na própria máquina do usuário: sem chave, sem custo por áudio. A voz do sistema entra como reserva quando o modelo não carrega.

6. Monitoramento

GET /functions/v1/status devolve banco, funções, modelos medidos, taxa de erro das últimas 24h e contadores. Serve para UptimeRobot, BetterStack ou um cron próprio.

Nada de chave secreta nesta página: só a chave pública do projeto aparece nos exemplos, e a sua chave nunca é exibida depois de criada.
